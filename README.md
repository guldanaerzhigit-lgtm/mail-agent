# Agent Web

Современный адаптивный веб-мессенджер в духе классического Mail.ru Agent. Проект использует Firebase для авторизации и обмена сообщениями; интерфейс размещается на Cloudflare Pages.

## Уже предусмотрено
- Регистрация и вход по email/паролю.
- Вход через Google (если включён в Firebase Authentication).
- Поиск пользователей и список контактов.
- Статусы присутствия.
- Личные чаты и сообщения в реальном времени.
- Отправка файлов (в рамках настроек Firebase Storage).
- Адаптивный интерфейс для компьютера и телефона.
- Установка как веб-приложения через manifest.

## Публикация на Cloudflare Pages
1. Откройте репозиторий `guldanaerzhigit-lgtm/mail-agent`.
2. В Cloudflare Dashboard перейдите в Workers & Pages и создайте Pages-проект из Git.
3. Подключите этот GitHub-репозиторий.
4. Для статического проекта оставьте команду сборки пустой, каталог вывода укажите `/` (корень репозитория).
5. Нажмите Deploy.

## Настройка перед реальным использованием
Проверьте конфигурацию Firebase в `app.js`, включите нужные способы входа в Firebase Authentication и настройте правила Firestore/Storage. Не публикуйте секретные серверные ключи. Публичная конфигурация Firebase обычно находится в клиентском коде, но доступ к данным должен ограничиваться правилами безопасности.

## Важно
Интерфейс и репозиторий не заменяют настройку Firebase. До проверки конфигурации и правил безопасности не используйте реальные личные данные.
