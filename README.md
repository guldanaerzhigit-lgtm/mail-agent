# Mail Agent — Old School
Current working Firebase messenger package.
Includes Firebase Auth, Firestore chat, users, emoji UI and PWA manifest.
Replace the Firebase config in app.js if deploying to another project.
Publish firestore.rules in Firebase Console.

## Added in this package
- 🔔 Browser notifications (permission requested after login)
- 🔊/🔇 incoming message sound toggle
- 🔢 unread message total
- 🟨 new-message banner when a new message arrives
